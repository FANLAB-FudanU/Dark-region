# Dark-region
This repository contains the bioinformatic analysis scripts used to investigate the genetic diversity and functional impact of variants in dark genomic regions of the Han Chinese population using long-read sequencing.

This scripts file includes eight parts: (1) reads mapping, (2) dark regions detection, (3) SNV calling, (4) positive selection analysis, (5) balancing selection analysis, (6) construction of LRS-based reference panel, (7) imputation to the independent Han Chinese cohort, and (8) PheWAS and conditional analysis.
